# RoseTrap

A lightweight Roblox launcher for Windows: FPS cap, potato mode, rendering options, fast flags and presets, wrapped in a rose-themed UI.

Built with C# / .NET 8 and [Avalonia 11](https://avaloniaui.net) (Skia-rendered, fully styleable, trimmable).

## Download

Grab `RoseTrap-vX.Y.Z-win-x64.exe` from [Releases](https://github.com/Kitte414414/RoseTrap/releases). It's one self-contained file (Windows 10/11, x64), so there's nothing to install and no .NET needed. Windows SmartScreen may warn because the exe isn't code-signed yet: choose *More info → Run anyway*.

New releases are built by GitHub Actions on Windows whenever a `v*` tag is pushed (see `.github/workflows/release.yml`).

## Layout

| Path | What's there |
| --- | --- |
| `src/RoseTrap.Core` | All non-UI logic, no dependencies: flag composition, `ClientAppSettings.json` writing, Roblox's `GlobalBasicSettings_13.xml`, install/update, launch, `roblox-player:` link handling. |
| `src/RoseTrap` | The Avalonia app: theme, pages, the character-drawn rose, the vine frame, tab transitions. |
| `tests/RoseTrap.Core.Tests` | Unit tests for the core. |
| `tests/RoseTrap.UiTests` | Headless UI tests that render every page with Skia and save screenshots (`ROSETRAP_SNAPSHOTS=<dir>`). |
| `design/` | The HTML prototype and the app icon source. |

## Build

```sh
dotnet test                                              # core + UI tests
dotnet run --project src/RoseTrap                        # run
dotnet publish src/RoseTrap -c Release -r win-x64        # trimmed single-file exe
```

## How settings reach Roblox

- **FPS cap and graphics quality** go into Roblox's own `%LocalAppData%\Roblox\GlobalBasicSettings_13.xml` (`FramerateCap`, `SavedQualityLevel`). Since September 2025 this is the only route that works: `DFIntTaskSchedulerTargetFps` is no longer honoured.
- **Fast flags** are merged into `ClientAppSettings.json`, next to the player and, optionally, in the global `%LocalAppData%\Roblox\ClientSettings`. RoseTrap only removes flags it owns, so entries you add by hand survive. The first write keeps a `.rosetrap.bak` backup of the original.
- **Allowlist only** (on by default) writes just the [18 flags Roblox still accepts](https://devforum.roblox.com/t/allowlist-for-local-client-configuration-via-fast-flags/3966569) and cleans the rest out of the file. Options that depend on legacy flags are marked "legacy" in the UI.
- **Install:** RoseTrap keeps its own copy of the player in `%LocalAppData%\RoseTrap\Versions`. It downloads packages from `setup.rbxcdn.com`, checks their MD5, and swaps in a new version only once it's complete. If it can't reach Roblox, it falls back to an existing official install.
- **Read-only files:** if your settings files are locked read-only, RoseTrap unlocks them for the write and locks them again. If a file still can't be written, Roblox starts anyway and you're told which setting didn't apply.

## Shaders

- **Colour grading** (presets such as Rose Bloom, Sunset Golden Hour, Cinematic and Noir, plus exposure, contrast, saturation, temperature, tint and fade) is applied as one colour matrix through the Windows Magnification API (`MagSetFullscreenColorEffect`). Nothing is injected into Roblox, so there's no anti-cheat risk. By default the grade is only active while Roblox is the window in front. It works in windowed and borderless fullscreen; exclusive fullscreen bypasses it. Windows removes the effect when RoseTrap exits, so RoseTrap minimises instead of closing while shaders are on.
- **Skyboxes** are generated by RoseTrap and written over the six `PlatformContent/pc/textures/sky/sky512_*.tex` files in its own Roblox copy; Roblox reads PNG data from them. The originals are kept next to them (`sky.rosetrap-original`) and restored for "Default". Games that set their own sky keep it.
- In-game lighting values (clock time, fog, atmosphere and so on) would need writing into Roblox's memory, which the anti-cheat treats as tampering and which can get accounts banned, so RoseTrap doesn't do it.
- **Why no reflections:** real screen-space reflections and relighting need the game's depth and normal buffers, which only exist inside Roblox's renderer. Tools that offer them (for example Masterstrap 3.4.0's "Shade (SSR)", which needs Direct3D 11 and its injection step) load code into the Roblox process. Hyperion, Roblox's anti-cheat, blocks or flags that, so RoseTrap stays with effects applied from outside the game. Roblox's own Future lighting (Global → Lighting) is the safe way to get real reflections and shadows where a game supports it.

## Gameplay and loading screen

- **Gameplay** edits the options from Roblox's Esc menu (sensitivity, invert camera, camera and movement mode, volume, fullscreen, performance stats, reduced motion, menu transparency) straight in `GlobalBasicSettings_13.xml`. Roblox rewrites that file when it closes, so changes made while Roblox is open are held and written at the next launch through RoseTrap.
- **Loading screen** is a RoseTrap window shown while launching. It shows the game's name, icon and picture from Roblox's public web APIs, and its stages only move on real events: the launcher's own steps, then lines in Roblox's log (`%LocalAppData%\Roblox\logs`) for joining, connecting and finishing loading. It closes when the game has loaded, Roblox exits, after two minutes, or when you hide it. It sits on top of Roblox's own loading screen; it doesn't change Roblox.

## Game presets

Allowlisted flag sets for kinds of games (shooters, battlegrounds, open worlds, simulators, horror). When you press Play on roblox.com, RoseTrap reads the place ID from the link and layers the matching preset between your graphics options and your own custom flags; custom flags always win.
